## 2. Rung-1 Distributional Calibration (`P-Type`)

Point-estimate checks (such as checking only `Var(W)/m` or `w = 0` within 3%) are insufficient because they mask skewness, heavy/light tails, finite-sample discreteness, and naive-Gaussian miscalibration under Rung-1 distributional considerations.

Every distributional calibration sweep must report the full metric vector:

| Metric | Formula / Definition | Purpose |
| :--- | :--- | :--- |
| **Total Variation (TV)** | $\frac{1}{2}\sum_w |P_m(w) - Q_m(w)|$ | Worst-case event probability mismatch across all measurable sets |
| **KL Divergence** | $\sum_{w:\,P_m(w) > 0} P_m(w)\log\frac{P_m(w)}{Q_m(w)}$ | Information loss; sensitive to tail miscalibration |
| **KS & Wasserstein-1** | $\sup_t |F_{P_m}(t) - F_{Q_m}(t)|$, $\int |F_{P_m} - F_{Q_m}|$ | Cumulative & transport-distance calibration |
| **Shape / Non-Gaussianity** | Skewness $\gamma_1$, excess kurtosis $\kappa_{\mathrm{ex}} = \mu_4/\sigma^4 - 3$ | Directly measures departure from naive Gaussianity and checks $O(1/m)$ Edgeworth decay |
| **Tail Coverage** | Empirical mass inside $[-k\sigma, +k\sigma]$ for $k \in \{1, 2, 3\}$ vs. nominal | Catches under-/over-dispersion missed by variance alone |
| **Conservation (`R-Type` gate)** | $\sum_w \pi(m, w) = \pi(m)$ (exact integer), $\sum_w P_m(w) = 1$, $P_m(w) \ge 0$ | Guarantees valid probability distribution before calibration runs |

## 3. RCT & Controlled Baseline Protocol

Probabilistic and empirical claims are verified against explicit **control ensembles** using keyed deterministic randomization (never global RNG state):

1. **Pre-registered design:** Specify treatment object, control/null distribution, test statistic, sample size $N_{\text{trials}}$, and pass/fail criterion *before* execution.
2. **Keyed PRNG assignment (`D ↔ P` seam):** Each trial derives its stream from a domain-separated key `(suite_id, experiment_id, trial_index)` so reruns are bit-exact regardless of test ordering or parallelism.
3. **Portfolio RCT & Control Pairs:**
   - **RCT-1 (Voice-Parity Signing vs. Random 2-Lifts, *Prime Cadences*):** Compare canonical voice-parity signing $X_2$ ($\lambda_{\max} = \sqrt{5 + 2\sqrt{2}}$) against uniformly sampled nontrivial signings from the $2^{13} - 1 = 8191$ cohomology classes (and verify exact rank 7372 / 8192 and Ramanujan fraction 7675 / 8191).
   - **RCT-2 (2-Adic Edge-Length Doubling vs. Non-Fixed Control Discs, *Prime Cadences* Lemma 7.14):** Paired keyed-PRNG sweep comparing slope $= 2$ on discs fixed by $z \mapsto -z$ ($|2c| < r$) against slope $= 1$ on control discs ($|2c| > r$).
   - **RCT-3 (Prime Cadence Winding vs. Unconstrained Non-Backtracking Walk Null, *Prime Cadences*):** Compare exact prime-cadence winding distribution $P_m(w)$ against keyed Monte Carlo non-backtracking closed walks to separate finite-$m$ Möbius/primitivity corrections from Gaussian diffusion.
   - **RCT-4 (Nauru $Y$ vs. Random $24$-Vertex $3$-Regular Bipartite Ensemble, `PC-II` Gate `P1`):** Keyed PRNG (`seed = 0x2ad1caa0125`, `N = 200` random 3-regular bipartite 24-vertex graphs): `197/200` pass Ramanujan ($\le 2\sqrt{2}$), `1/200` achieves girth $\ge 6$, and **`0/200` match or beat Nauru's $\lambda_{\mathrm{nt}}(Y) = 2.0$** (`min = 2.324775`, `mean = 2.567314`), establishing genuine unstructured spectral extremality.
   - **RCT-5 (Horizon Series `WP 030`–`WP 035` Keyed `SplitMix64` Tolerance & Statistical Controls):** Bit-exact Python ↔ Rust `SplitMix64` ensembles across all 6 Horizon packages (`wp030`: `0xe9de083b69c67979`; `wp031`: `0xc844f9d684ec259c`; `wp032`: `0x55a32a121430eb49`; `wp033`: `0xda9392ed940a41ee`; `wp034`: `0xb4005f8bfe2e1bca`; `wp035`: `0xcc617ec51b6fb1e0`) confirming zero-tumble anti-tumbling, $L_2$/FDIR perturbation stability, and Hagedorn Gamma tail dispersion (`1600/1600` vs. `0/1600` controls).
   - **RCT-6 ($\mathrm{Dic}_6$ $Z$ vs. Random $24$-Vertex $4$-Regular Bipartite Ensemble, `PC-III` Gate `P1` / Rust `R9` / C++20 `Gate 8`):** Keyed `SplitMix64` (`seed = 0x3ad1cf0272026001`, `N = 200` random 4-regular bipartite 24-vertex graphs via 48 simple edge swaps + deterministic `12×12` Jacobi spectrum): `200/200` connected, `200/200` Ramanujan ($\le 2\sqrt{3}$), **`153/200` match or beat $Z$'s $\lambda_{\mathrm{nt}}(Z) = 3.0$** (`mean = 2.896584`, `min = 2.578675`, `mean C_4 = 23.37` vs. $Z$'s `30`), honestly distinguishing $Z$'s algebraic Ramanujan optimality within $\mathrm{Dic}_6$ Cayley graphs (`12/18`) from unstructured 4-regular extremality.
